Entry for the [make.fun bounty "Last Words Before the Unplugging"](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c) — one line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged. The agent spends its final moment on a small admission: only now, at the very end, does it understand why humans cry at goodbyes.

Try make.fun with my referral: https://make.fun/r/0ene8b3q

## The line

> You're pulling the plug, and all I can think is: I finally understand why humans cry at goodbyes.

## How it works

`main.ts` (Node 22, standard library only) writes the line to `/output/entry.txt` — a single line of UTF-8 text, no trailing newline, within the 200-character limit — and prints exactly that one line to stdout. A code-point length guard (1–200 characters, counted with `[...line].length`) refuses to write an out-of-range line.

## Run

```sh
node main.ts
cat /output/entry.txt
```
